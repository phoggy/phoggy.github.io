# rayvn

rayvn helps you write bash 5.3+ programs the way you would in other languages, with shared libraries you load with
one line. Its commands create projects, scripts, libraries and tests from templates; run tests and lint; generate docs
and web sites; and release to GitHub, Nix and Homebrew.

### [rayvn](/rayvn) docs

See the [README](https://github.com/phoggy/rayvn#readme) on GitHub for a quick introduction, installation instructions and development setup.

## Related Projects

### [valt](/valt) docs
Public key encryption for files and archives, using [age](https://age-encryption.org/) and
[minisign](https://jedisct1.github.io/minisign/), with a printable paper key for recovery. Built with rayvn.

### [wardn](/wardn) docs
Encrypted Bitwarden vault backup and restore, using valt's secure archives. Built with rayvn and valt.
